Neo4j-Driven AI Chatbot with Knowledge Graph and LLM Integration

Code

{Llama 3.2, Neo4j, HybridSearch, LangChain}

This project utilizes the cutting-edge AI AssistPro Smart Agent for Customer Interaction system that combines the power of Neo4j Knowledge Graphs, Retrieval-Augmented Generation (RAG), Hybrid Search, and LLM to provide contextually accurate responses across PDF, CSV, and TXT datasets. This project idea leverages the strengths of graph-based reasoning and generative AI for dynamic, real-time querying and scalable conversational experiences, ideal for enterprise applications.

🚀 Features:
🔗 Neo4j Knowledge Graph Integration: Organizes and manages structured knowledge for enhanced context-awareness.

SmartDocuFix: Intelligent Document Detection & Rotation Correction

Code Live

{YoloV11, Flask, OpenCV}

This project is designed to segment documents from images using the YOLOv11 segmentation model and correct their orientation if they are rotated, similar to CamScanner. The model is trained on various types of documents and integrated into a Flask web application for easy usage.

🚀 Features:
📄 Document Segmentation: Detects and extracts documents from images using a trained YOLOv11 segmentation model.
🔄 Orientation Correction: Automatically corrects rotated documents to align them properly.
🌐 Flask API: Provides a simple web interface for uploading images and obtaining processed results.
🐳 Docker Support: Easily deployable using Docker.

AIAgentInsight: Multi-Agent Product Analyzer

Code

{Langchain, LLama3.3, Crawl4ai, Streamlit}

AIAgentInsight is a Streamlit-based web application designed to provide detailed insights and recommendations for analyzing product or company-related queries. It utilizes various agents for scraping, validating, and summarizing data from platforms like G2, Crunchbase, and DuckDuckGo, combined with the power of LLMs for query analysis and summary generation.

🚀 Features:
🔎 Query Analysis: Analyze user queries to identify the product or company and generate search recommendations.
📝 G2 Reviews Extraction: Fetch detailed product reviews, ratings, and sentiments from G2.
📊 Crunchbase Insights: Aggregate and extract business-related insights from Crunchbase.
🌍 Web Content Search: Perform searches based on query recommendations and clean the extracted content.
📄 Summary Generation: Combine data from multiple sources to generate a cohesive business analysis summary.

Code Live

Name Entity Recognition (NER) with MISTRAL, BERT, and FLAN T5

Code

{MISTRAL, BERT, FLAN T5, Unsloth}

The project focuses on Developing a Name Entity Recognition system trained and implemented using MISTRAL, BERT, and FLAN T5 models. Utilized the Bangla-BERT model to identify and classify entities such as persons, organizations, locations, objects, mail, etc from Bangla text. Mistral and Flan T5 models were fine-tuned on a Cyber Security dataset for Software and Security Entities such as Software Versions, Programming Languages, Files or Functions, Applications or Software Names, Operating Systems etc from English text..

Image To Caption Generator DeepLearning Project

Code

{Encoder, Decoder, Attention, ResNet101, LSTM}

This project focused on image captioning that generates descriptive captions for images using deep learning techniques. Utilized a pre-trained CNN (ResNet101) as an encoder to extract features from images for generating descriptive captions. Implemented an LSTM decoder to generate captions based on the extracted image features, forming a complete image captioning system using deep learning techniques
